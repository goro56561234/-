# えほんアトリエ

「誰でも、物語に命を吹き込める。」プログラミング不要のデジタル仕掛け絵本エディタです。React / TypeScript / Viteで構成し、サーバー・ログイン・有料APIは不要です。

## 起動

Node.js 22以上とnpmを使用します。

```sh
npm ci
npm run dev
```

ターミナルに表示されたURLをブラウザで開きます。

```sh
npm run build             # 型チェックと本番ビルド
npm run preview           # ビルド結果の確認
npm test                 # データ形式のテスト
npx playwright install chromium
npx playwright test       # ブラウザで基本操作を確認
# Chromiumが既にある環境: CHROMIUM_PATH=/usr/bin/chromium npx playwright test
```

## 使い方

初回は全5ページの「ふしぎな森の小さなおうち」が開きます。上部の「プレビュー」で絵に触れると、扉が開き、花が咲くように膨らみ、蝶が飛び、星がきらめき、うさぎが跳ねます。

- 左のページ一覧から選択し、追加・複製・削除・上下の矢印で順序を変更できます。先頭のページが表紙です。
- 「素材」から内蔵SVG、「画像」からPNG/JPEG/WebP（1画像8MBまで）を追加できます。画像ファイルを中央へドロップすることもできます。
- イラストや文字をドラッグして配置します。右パネルで幅・高さ・回転・重なり順・複製・削除を操作します。幅と高さは個別指定です。
- 「文字」で文章を追加し、本文・書体・サイズ・色を変更できます。
- 右パネルで8種類の仕掛けを設定します。動きの時間、対応する動きの移動距離や回転角度を調整できます。「画像を切り替え」では切り替え先画像を追加してください。
- キャンバスの余白をクリックすると背景色を変更できます。
- 上部の矢印ボタンで取り消し・やり直し。Ctrl / Cmd + Z、Shift付きでやり直しにも対応しています（入力欄では通常の文字編集）。履歴は最大40操作です。
- 「プレビュー」は編集から独立した閲覧モードです。ページ送り、タッチでの仕掛け実行、全画面（対応ブラウザのみ）、左右キーでのページ送り、Escapeで編集に戻れます。
- 左上ロゴまたは「作品一覧」で本だなを開き、新規作成・再編集・作品削除・サンプル追加ができます。スマートフォンではロゴから開きます。

## 保存とバックアップ

変更から約450ms後にIndexedDBへ自動保存します。画像はData URLとして作品に含めます。再読み込みすると最後に更新した作品が復元されます。表示中のページは再起動時に表紙へ戻ります。

「書き出し」でJSONをダウンロードし、本だなの「JSONを読み込む」で別作品として復元できます。元の作品を上書きしません。保存データは端末・ブラウザ・サイトのURLごとに独立します。ブラウザデータの削除・プライベートモード終了で失われる場合があるため、定期的にJSONを保管してください。容量不足時はエラーを表示します。インポートは60MB / 100ページ / 1ページ500要素までです。

## GitHub Pagesで公開

1. このプロジェクトをGitHubリポジトリの `main` にpushします。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. 同梱の `.github/workflows/deploy.yml` がビルドして公開します。Actions画面から手動実行もできます。

`vite.config.ts` の `base: './'` により、リポジトリ名 `-` を含む任意のサブパスでアセットを相対参照できます。SPAのパスルーティングを使わないため、リロード時の404回避設定は不要です。公開されるのはアプリのみで、ユーザーの絵本はブラウザ内に保持されます。
